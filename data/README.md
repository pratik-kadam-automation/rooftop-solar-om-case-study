# Sample data

Everything in `data/sample/` is synthetic. It was generated by `tools/make_sample_data.py` with a fixed
random seed so the tests and the README outputs can be reproduced. None of it comes from a real plant.

- `string_currents.csv`: 10-minute string currents for 2 inverters with 8 strings each over 10 days.
  One string starts about 45 minutes late every day, one starts late on some days, one stops starting at all.
- `fault_log.csv`: a small string-fault log across three inverters.
- `daily_energy.csv`: 40 days of AC energy and plane-of-array irradiation for a 930 kWp array, with soiling building up.
- `cleaning_dates.csv`: two cleaning dates inside that period.

Regenerate with `python -m tools.make_sample_data`.
